# Playstation-Revamp integration

The post-intro experience is ported from [Manav-Sonawane/Playstation-Revamp](https://github.com/Manav-Sonawane/Playstation-Revamp). The upstream project has no published license file. The NJengines owner confirmed permission to copy this project for personal use. This notice records provenance; it does not grant or assert rights on behalf of the upstream author.

The copied interface includes source mock data and demo interaction flows. In particular, sample games, profiles, friends, achievements, and checkout are not connected to PlayStation or payment services. Cross-device remote control depends on the upstream Express WebSocket relay, which this TanStack Start/Vercel app does not host; the QR screen and remote interface state that limitation rather than claiming an active connection.
